# Media-Manager

A Java-based console application designed to manage different types of media, including images, music, and videos.

Features

Add images, music, and videos with their respective codecs.

Display stored media information.

Filter media by type.

Navigate through an interactive console menu.

Technologies Used

Java

Object-Oriented Programming (OOP)

Inheritance and Polymorphism

Abstract Classes and Interfaces

ArrayList

How to Run

Download the Java source files.

Open a terminal in the project directory.

Compile the program using javac *.java.

Run the application using java Assignment4.
